Bias of MLE for estimated variance components

We motivated REML as an alternative to the usual maximum likelihood estimator by saying that the MLE is biased, and REML is trying to help correct that bias. The purpose of this portion of the assignment is to see this in action.

Let’s simulate a small dataset from a linear mixed model, and compute the ML and REML estimates of the variance components \(\boldsymbol{\theta}\):

set.seed(5163)

ni <- 10 # observations per group
m <- 5 # number of groups
var_x <- 1 
var_e <- 1
var_u <- 2
beta0 <- 1 # overall intercept
beta1 <- 0 # overall slope

# generate group ids and X
group_id <- rep(1:m, each=ni)
x_means <- rnorm(m, sd=sqrt(var_x))[group_id]
x <- x_means + rnorm(ni*m)

# generate u, e, and Y
u <- rnorm(m, sd=sqrt(var_u))[group_id]
y <- beta0 + u + beta1*x + rnorm(m*ni, sd=sqrt(var_e))

# REML estimate
m_sim <- lme4::lmer(y ~ x + (1|group_id))
data.frame(lme4::VarCorr(m_sim))$vcov
[1] 6.543349 0.649868
# MLE
m_sim2 <- lme4::lmer(y ~ x + (1|group_id), REML = F)
data.frame(lme4::VarCorr(m_sim2))$vcov
[1] 5.1945744 0.6357491

REML estimates

Examples 9.9 and 9.10 in the supplementary notes give examples of estimating variance components for a mixed model with a random intercept, using both ML and REML.

In this portion of the assignment, you will use a similar process to estimate variance components using REML for a mixed model with a random intercept and a random slope.

The code below simulates data from the mixed model

\[ Y_{ij} = (\beta_0 + a_i) + (\beta_1 + b_i)X_{ij} + \varepsilon_{ij} \]

with \(m = 15\) groups and \(n_i = 40\) observations in each group \(i\). The true variance parameters are \(\sigma_a^2 = 2\), \(\sigma_b^2 = 1\), \(\rho_{ab} = 0\), \(\sigma_\varepsilon^2 = 1\).

set.seed(29234)

# simulation parameters
ni <- 40 # observations per group
m <- 15 # number of groups
var_x <- 1 
var_e <- 1
var_a <- 2
var_b <- 1
beta0 <- 1 # overall intercept
beta1 <- 3 # overall slope

# generate group ids and X
group_id <- rep(1:m, each=ni)
x_means <- rnorm(m, sd=sqrt(var_x))[group_id]
x <- x_means + rnorm(ni*m)

# generate u, e, and Y
a <- rnorm(m, sd = sqrt(var_a))[group_id]
b <- rnorm(m, sd = sqrt(var_b))[group_id]
y <- beta0 + a + beta1*x + b*x + rnorm(m*ni, sd=sqrt(var_e))

We can then fit the LMM with lme4 (using REML by default) and examine the estimated variance components:

# fit the LMM
m1 <- lme4::lmer(y ~ x + (x|group_id))
data.frame(lme4::VarCorr(m1))$vcov
[1]  1.6904355  1.0814729 -0.1492076  0.9843459

From left to right, these are: \(\widehat{\sigma}_a^2\), \(\widehat{\sigma}_b^2\), \(\widehat{\rho}_{ab} \widehat{\sigma}_a \widehat{\sigma}_b\), and \(\widehat{\sigma}_{\varepsilon}^2\).

Predicting random effects

In addition to estimating the fixed effect coefficients \(\boldsymbol{\beta}\), we also need to predict the random effects \(\boldsymbol{u}\) in order to make predictions for the observed responses \(\mathbf{y}\). Note that I say predict the random effects (rather than “estimate”), because the random effects are random variables rather than fixed parameters.

Since \(\boldsymbol{u}\) is random, it has a distribution. Our initial distribution is \(\boldsymbol{u} \sim N(\mathbf{0}, \mathbf{G}_{\boldsymbol{\theta}})\). Once we have observed the data, we can write down a distribution for \(\mathbf{u}|\mathbf{y}, \mathbf{X}, \mathbf{Z}\).

It turns out that

\[ \mathbb{E}[\mathbf{u}|\mathbf{y}, \mathbf{X}, \mathbf{Z}] =\mathbf{G}_{\boldsymbol{\theta}} \mathbf{Z}^T \boldsymbol{\Sigma}_{\boldsymbol{\theta}}^{-1}(\mathbf{y} - \mathbf{X}\boldsymbol{\beta}) \tag{1}\]

Under the principle that we should predict a random variable with its conditional mean (just like we do in regression), then the predicted random effects for a linear mixed model are given by

\[ \widehat{\boldsymbol{u}} = \mathbf{G}_{\widehat{\boldsymbol{\theta}}} \mathbf{Z}^T \boldsymbol{\Sigma}_{\widehat{\boldsymbol{\theta}}}^{-1}(\mathbf{y} - \mathbf{X}\widehat{\boldsymbol{\beta}}) \]

Derivation

The purpose of this exercise is to verify Equation 1. To do so, we will use the fact that we can write the joint vector \(\begin{bmatrix} \mathbf{y} \\ \boldsymbol{u} \end{bmatrix}\) as

\[ \begin{bmatrix} \mathbf{y} \\ \boldsymbol{u} \end{bmatrix} = \begin{bmatrix} \mathbf{X} \boldsymbol{\beta} \\ \mathbf{0} \end{bmatrix} + \begin{bmatrix} \mathbf{Z} & \mathbf{I} \\ \mathbf{I} & \mathbf{0} \end{bmatrix} \begin{bmatrix} \boldsymbol{u} \\ \boldsymbol{\varepsilon} \end{bmatrix} \tag{2}\]
