Class activity: Fitting ZIP models

ZIP model

The full specification for a ZIP model is:

\[ \begin{aligned} P(Y_i = y | \mathbf{x}_i) &= \begin{cases} e^{-\lambda_i}(1 - p_i) + p_i & y = 0 \\ \dfrac{e^{-\lambda_i} \lambda_i^y}{y!}(1 - p_i) & y > 0 \end{cases} \\ \log(\lambda_i) &= \mathbf{x}_i^T \boldsymbol{\beta} \\ \log \left( \frac{p_i}{1 - p_i} \right) &= \mathbf{x}_i^T \boldsymbol{\gamma} \end{aligned} \]

Weekend drinking

Survey data from 77 college students on a dry campus (i.e., alcohol is prohibited) in the US. Survey asks students “How many alcoholic drinks did you consume last weekend?”

  • drinks: number of drinks the student reports consuming
  • sex: whether the student identifies as male
  • OffCampus: whether the student lives off campus
  • FirstYear: whether the student is a first-year student

Our goal: model the number of drinks students report consuming. We fit a zero-inflated Poisson model:

library(tidyverse)

Parameter estimation for ZIP models

The unknown parameters in a ZIP model are \(\boldsymbol{\beta}\) and \(\boldsymbol{\gamma}\). How should we estimate these parameters?

Maximum likelihood estimation

As usual, we can estimate \(\boldsymbol{\beta}\) and \(\boldsymbol{\gamma}\) by maximizing a likelihood. Let \(\boldsymbol{\theta} = \begin{pmatrix} \boldsymbol{\beta} \\ \boldsymbol{\gamma}\end{pmatrix}\) be the combined vector of parameters. Then, the log-likelihood function is

\[ \log L(\boldsymbol{\theta} | \mathbf{y}, \mathbf{X}) = \sum \limits_{i=1}^n \log P(Y_i | \mathbf{x}_i, \boldsymbol{\theta}) \]

where \(P(Y_i | \mathbf{x}_i, \boldsymbol{\theta})\) is calculated using the piecewise formula above.

In the questions below, we will write code to compute the log-likelihood for a ZIP model.

Optimizing

Now we can estimate our parameters by maximizing the log likelihood.

How should this be done? One option would be to use Newton’s method: find the gradient and the Hessian of the log-likelihood and solve iteratively, as we usually do.

However, taking derivatives of the log-likelihood will be quite difficult, because we have the logarithm of a sum in the case that \(Y_i = 0\).

An alternative is to use built-in optimization methods in R, with the optim function (this is exactly how the pscl::zeroinfl function estimates the parameters!). The optim function only requires that we specify (a) an initial guess for the coefficients, and (b) a function to minimize. We don’t have to specify a gradient or Hessian (optim can use a finite-difference approximation for the gradient, and has a variety of ways to handle the Hessian)

In this case, we our initial estimate of \(\boldsymbol{\beta}\) will be given by the coefficients of a Poisson regression, and our initial estimate of \(\boldsymbol{\gamma}\) will be \(\left( \log \left( \dfrac{\overline{Y}}{1 - \overline{Y}} \right), 0, 0,..., 0 \right)\).

By default, optim minimizes a function, so we will minimize the negative log likelihood.

The code then looks like:

zero_prop = mean(m1$y == 0)
gamma0 = c(log(zero_prop/(1 - zero_prop)), 0, 0, 0)
beta0 = coef(glm(drinks ~ sex + FirstYear + OffCampus, 
                 family = poisson, data = wdrinks))
theta0 = c(beta0, gamma0)

optim_est <- optim(theta0, 
      function(theta) -log_lik_zip(m1$y, model.matrix(m1), theta),
      method = "BFGS")
