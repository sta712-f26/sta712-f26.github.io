Data

To investigate the effect of AI on user productivity, researchers conducted a randomized experiment with 16 experienced software developers. The authors specified 246 different software development tasks, and randomly assigned each task to be completed with or without AI. The tasks were then divided between the different developers, and the researchers recorded the time it took to complete each task.

Each row in the data represents one task. We will work with the following variables:

  • dev_id: unique ID for each developer
  • predicted_time_no_ai: How long the developer estimated the issue would take without AI (minutes)
  • ai_treatment: 0 if AI use was not allowed, 1 if AI use was allowed
  • initial_implementation_time: Time taken by the developer to solve the issue and create an initial pull request (an initial solution) (minutes)

The data can be loaded into R with the following:

library(tidyverse)

metr_ai <- read_csv("https://cmustatistics.github.io/data-repository/data/metr-ai.csv")

Model

To investigate the effect of AI use, we will begin with the following mixed model:

\[\text{T}_{ij} = (\beta_0 + a_i) + (\beta_1 + b_i) \text{AI}_{ij} + \beta_2 \text{EstTimeNoAI}_{ij} + \varepsilon_{ij}\]

\[\varepsilon_{ij} \sim N(0, \sigma_{\varepsilon}^2) \hspace{0.5cm} \begin{bmatrix} a_i \\ b_i \end{bmatrix} \sim N\left( \begin{bmatrix} 0 \\ 0 \end{bmatrix}, \begin{bmatrix} \sigma_a^2 & \rho_{ab} \sigma_a \sigma_b \\ \rho_{ab} \sigma_a \sigma_b & \sigma_b^2 \end{bmatrix} \right)\]

where \(\text{T}_{ij}\) is the initial completion time for developer \(i\) on task \(j\), \(\text{AI}_{ij}\) is 1 if AI use was allowed on the task, and \(\text{EstTimeNoAI}_{ij}\) is the developer’s guess for the time it would take to complete the task without AI (the guesses were made before being assigned the tasks).

We also have both a random intercept \(a_i\) (capturing variability in the overall completion time between developers) and a random slope \(b_i\) (capturing differences in the effect of AI between developers).

Parametric bootstrap CI

An alternative approach to doing inference with mixed models is parametric bootstrapping. If we wanted to compare nested model, we would parametric bootstrap from a reduced model. Here, though, we just want a confidence interval for a single coefficient, so we can bootstrap from the fitted model above (m1). Of course, this does assume that the fitted model is approximately correct!

Our parametric bootstrap sample requires creating new response values \(\text{T}_{ij}^*\), given by

\[\text{T}_{ij}^* = (\widehat{\beta}_0 + a_i^*) + (\widehat{\beta}_1 + b_i^*) \text{AI}_{ij} + \beta_2 \text{EstTimeNoAI}_{ij} + \varepsilon_{ij}^*\]

This requires sampling (1) new residuals \(\varepsilon_{ij}^* \overset{iid}{\sim} N(0, \widehat{\sigma}_\varepsilon^2)\) and (2) new random effects

\[ \begin{bmatrix} a_i^* \\ b_i^* \end{bmatrix} \overset{iid}{\sim} N\left( \begin{bmatrix} 0 \\ 0 \end{bmatrix}, \begin{bmatrix} \widehat{\sigma}_a^2 & \widehat{\rho}_{ab} \widehat{\sigma}_a \widehat{\sigma}_b \\ \widehat{\rho}_{ab} \widehat{\sigma}_a \widehat{\sigma}_b & \widehat{\sigma}_b^2 \end{bmatrix} \right) \]

In matrix form, this looks like:

\[ \mathbf{y}^* = \mathbf{X} \widehat{\boldsymbol{\beta}} + \mathbf{Z} \boldsymbol{u}^* + \boldsymbol{\varepsilon}^* \]

where \(\boldsymbol{u}^*\) is the combined vector of all the \(a_i^*\)s and \(b_i^*\)s.

Fitted values

The fixed effect fitted values \(\mathbf{X} \widehat{\boldsymbol{\beta}}\) can be extracted from the model with

# fixed effect piece
fitted_values <- predict(m1, re.form = NA)

Simulating \(\boldsymbol{u}^*\)

Since the random effects are assumed to come from a bivariate normal distribution, we have to simulate a little differently. We will use the mvrnorm function from the MASS package to sample from a bivariate normal. The code below simulates the random effects:

variance_ests <- as.data.frame(VarCorr(m1))$vcov

# variance-covariance matrix for the random effects
G <- matrix(c(variance_ests[1], variance_ests[3],
              variance_ests[3], variance_ests[2]),
            nrow = 2)

ab_sim <- MASS::mvrnorm(n = 16, mu = c(0, 0), Sigma = G)
u <- as.vector(t(ab_sim))

Bootstrap resampling?

When we have created bootstrap confidence intervals previously, we have used bootstrap resampling (the nonparametric bootstrap) rather than parametric bootstrapping. The advantage of bootstrap resampling is that we should still get good estimates of the standard error even when the model is mis-specified, whereas the parametric bootstrap assumes that the model is correct.

From our diagnostics in the last class activity, there was some concern about normality of the errors. Can we use bootstrap resampling for grouped data with a mixed effects model? Sort of. But we have to resample differently.

Since the observations are correlated within groups, we can no longer sample rows independently with replacement. Rather, we need to resample groups (in this case, the developers) with replacement.

Here is code to accomplish this resampling:

# resample developers
boot_devs <- metr_ai |>
    pull(dev_id) |>
    unique() |>
    sample(16, replace=TRUE)
  
# create a new bootstrap dataset with the 
# sample of developers
ai_boot <- data.frame(new_id = 1:16, 
                        dev_id = boot_devs) |>
    left_join(metr_ai, join_by(dev_id)) |>
    select(-dev_id) |>
    rename(dev_id = new_id)
