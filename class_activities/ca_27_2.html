Class activity: fitting ZINB models

Zero-inflated count model

In general, a zero-inflated count model is:

\[ \begin{aligned} P(Y_i = y | \mathbf{x}_i) &= \begin{cases} f(0; \boldsymbol{\xi}_i)(1 - p_i) + p_i & y = 0 \\ f(y;\boldsymbol{\xi}_i)(1 - p_i) & y > 0 \end{cases} \\ \log(\mu_i) &= \mathbf{x}_i^T \boldsymbol{\beta} \\ \log \left( \frac{p_i}{1 - p_i} \right) &= \mathbf{x}_i^T \boldsymbol{\gamma} \end{aligned} \]

Here \(f(y; \boldsymbol{\xi}_i)\) represents a count distribution with mean \(\mu_i\). The vector \(\boldsymbol{\xi}_i\) captures the parameters needed to specify that distribution.

For a zero-inflated Poisson (ZIP) model, for example, \(\boldsymbol{\xi}_i = \mu_i\) and \(f(y; \boldsymbol{\xi}_i) = \dfrac{e^{-\mu_i} \mu_i^y}{y!}\).

For a zero-inflated negative binomial (ZINB), \(\boldsymbol{\xi}_i = (\mu_i, r)\) and \(f(y; \boldsymbol{\xi}_i)\) is the pmf for a negative binomial with mean \(\mu_i\) and size parameter \(r\).

Parameter estimation

Like a ZIP model, parameters can be estimated for a ZINB model by the method of maximum likelihood.

Previously, we wrote code to compute the log likelihood for a ZIP model. We then used R’s optim function to maximize the likelihood (by minimizing the negative log likelihood).

Optimizing

We can now use the optim function to estimate \(\boldsymbol{\beta}, \boldsymbol{\gamma}, r\).

For example, here are estimates for ZINB coefficients with the NMES physician visit data. We initialize estimates of \(\boldsymbol{\beta}\) and \(r\) for a negative binomial fit (without zero-inflation) on the data.

library(tidyverse)
library(AER)

data("NMES1988")
nmes <- NMES1988 |>
  select(visits, hospital, health, chronic, 
         gender, school, insurance)

nb_fit <- MASS::glm.nb(visits ~ ., data = nmes)

zero_prop = mean(nmes$visits == 0)
beta0 = coef(nb_fit)
gamma0 = c(log(zero_prop/(1 - zero_prop)),
           rep(0, length(beta0) - 1))
params0 = c(beta0, gamma0, nb_fit$theta)

optim_est <- optim(params0, 
                   function(par) -log_lik_zinb(nmes$visits, model.matrix(nb_fit), par),
                   method = "BFGS")
